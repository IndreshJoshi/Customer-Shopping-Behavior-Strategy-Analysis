# Customer Shopping Behavior & Strategy Analysis

## 📌 Project Overview

This project analyzes customer shopping behavior to identify purchasing patterns, customer segments, and key business trends. The analysis uses SQL, Python, and Power BI to transform raw customer data into meaningful business insights.

## 🛠️ Tools & Technologies

* SQL / PostgreSQL
* Python
* Pandas
* NumPy
* Power BI
* Git & GitHub

## 🔍 Project Workflow

1. Cleaned and validated the customer dataset.
2. Performed exploratory analysis using Python and Pandas.
3. Used SQL queries, CTEs, subqueries, and window functions for deeper analysis.
4. Identified customer purchasing patterns and business trends.
5. Created an interactive Power BI dashboard to visualize key insights.
6. Presented insights in a business-friendly format to support decision-making.

## 📊 Key Analysis Areas

* Customer purchasing behavior
* Product and category performance
* Customer segmentation
* Spending patterns
* Sales trends
* Customer demographics
* Business performance indicators
